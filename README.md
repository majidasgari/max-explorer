# max-explorer

A web browser for KDE (Linux) and Windows — macOS and Android planned later.

**Status:** pre-alpha. The repository currently holds the project contract
([`AGENTS.md`](AGENTS.md)); no code yet.

- Engine: Chromium via [CEF](https://bitbucket.org/chromiumembedded/cef)
- Shell: C++20 + Qt 6 Widgets, built with CMake
- Not Electron — see "نقش و استک" in `AGENTS.md` for why.
